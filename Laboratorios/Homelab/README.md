# 🧪 Homelab & Práticas Pessoais
#### 🖥️ Infraestrutura, Redes e Segurança por Conta Própria

---

## 📌 Visão Geral

Este espaço é dedicado ao registro de laboratórios práticos, simulações e projetos de infraestrutura que desenvolvo de forma independente. O objetivo é aplicar conceitos teóricos de redes e segurança em ambientes controlados, testando configurações e ferramentas reais.

---

## 🛠️ Tecnologias e Ferramentas

*   **Simulação:** 🌐 Cisco Packet Tracer, GNS3
*   **Virtualização:** 💻 Oracle VM VirtualBox, VMware
*   **Sistemas:** 🐧 Linux (Debian/Ubuntu/CentOS), 🪟 Windows Server
*   **Análise:** 🕵️ Wireshark, Nmap
